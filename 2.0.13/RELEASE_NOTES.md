# STO 2.0.13

18 September 2026

What’s new since 2.0.12:

- STO checks that this copy is allowed to open before the rest of the app starts.
- If this copy is too old, you see Update required and can download the setup file directly.
- The sidebar Version page shows the version on this PC, the published installer, and notes. Version is checked when the app opens.
- Starting a timer can prefill billing (and job account when used) from this employee’s last time on that work order, or their most-used billing on a new work order.
