# STO 2.0.14

7 October 2026

What’s new since 2.0.13:

- Success closes the form and shows a short toast. Failure stays on the form. Saves lock while they run. Phase change, payroll reopen, and archive without an order ask you to confirm first.
- New Team permission: Add attachment to sales order.
- Time entries that have a mobile file show that file in Time Admin and Time Tracking. Photos open in the app. Other files open on this computer.
- A communication note is attached to the work order whenever the note has content, even when no service type is selected.
- Operations hours are shown by employee and labour group, with billing codes under each person.
- The master password can save and switch full setups by Spire company and database. Saving an existing pair asks before it replaces that setup.
