# STO 2.0.15

20 November 2026

What’s new since 2.0.14:

- You can create STO orders, track time on them, and see the hours in payroll and reports. That time is not sent to Spire.
- Each employee can have different weekly auto hours.
- Time Admin is easier to scan. STO time is marked, and you can edit it until the payroll period is closed.
- The Team page is easier to manage. Permissions and passwords open in one window, with search and a next person.
